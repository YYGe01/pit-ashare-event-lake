# 2026年05月14日

## 采集计划口径重写

- 背景：用户确认基础结构化行情应由上层 `E:\code\qlib` 和社区 `cn_data` 维护，QDC 不再每天全 A 自采日线和复权因子。
- 调整：将项目主线从“自建全量行情数据中心”改为“基于 Qlib 行情底座的 A 股事件与文本因子中心”。
- README：默认入口改为 `crawl-daily`、`build-factors`、`sync-parquet`、`quality`、`console`；`daily-pipeline`、`plan-backfill`、`run-backfill` 降级为历史/诊断能力。
- 每日计划：重写为每日非结构化采集与 Qlib 外部因子计划，明确公告、新闻、研报、舆情等为当前主线。
- 迁移总纲：明确 Qlib / 社区 `cn_data` 负责 `$open/$high/$low/$close/$volume/$factor`、交易日历和 instruments，QDC 只消费、校验并输出 external factors。
- 训练评估：不再建议先补齐 QDC 自采 2015 至今基础行情，改为先更新 Qlib `cn_data`，再评估 QDC 公告/新闻/研报等外部因子。
- 数据流阅读指南：补充 2026-05-14 新口径，说明 `daily_bar`、`adj_factor`、完整 `export-qlib` provider 只作为历史能力、smoke 和兼容链路。
- 控制台设计：将首页目标调整为 Qlib provider 新鲜度、文档源采集状态、外部因子构建状态；历史回补和 `daily-pipeline` 只保留为诊断视图。

## P0 每日非结构化链路落地

- Qlib provider：新增配置 `qlib_provider.provider_uri` 和 required fields；`qdc verify-qlib` 默认检查 `$close/$volume/$factor`，先验证 `calendars/day.txt`、feature 文件和日历新鲜度，再通过 Qlib `D.features` 抽样读取。
- 控制台：每日状态 payload 和首页新增 `Qlib Provider` 状态，展示 provider 路径、最新日历、预期日期、样本 instrument 和问题数；首页文案从“QDC 自采基础行情完整率”转向“Qlib provider + 文档因子链路”。
- 公告链路：`crawl-run` / `crawl-daily` 默认 metadata-only，不再默认下载 PDF；需要留存 PDF 时显式使用 `--download-pdfs`，仍可用 `--pdf-limit` 控制下载量。
- 新闻源：默认每日源收敛为 `sina_finance_news` 和 `eastmoney_roll_news`，`nbd_company_news` 退出默认源并保留为手动 smoke。
- 源级指标：新闻 crawler 的结果和 document bundle manifest 统一记录 `empty_result_rate`、`duplicate_rate`、`parse_failed_rate` 和 `mapping_rate`，用于观察空结果、重复、解析失败和标题/正文到 instrument 映射情况。

## 控制台首页优化

- 首页结构：新增顶部状态条，首屏改为“今日结论 / 源级健康 / 因子状态 / 操作建议”，弱化 `daily_bar`、`adj_factor`、`price_limit` 覆盖率。
- 源级健康：默认展示 `cninfo_announcement`、`sse_announcement`、`eastmoney_roll_news`、`sina_finance_news` 和手动 `nbd_company_news`；从 document manifest 汇总 provider 记录数、空结果、重复率、解析失败率和映射率。
- 因子状态：突出 `daily_announcement_factor` 和 `daily_news_factor` 当日行数、标的数以及是否匹配 `QdcAlpha158WithExternal` 外部字段。
- 操作建议：按当前日期生成 `verify-qlib`、`crawl-daily` 和 `build-factors` 复制命令。
- 控制台操作：启动采集默认执行 `crawl-daily`，保留 `daily-pipeline` 作为历史流水线选项；执行状态卡片展示公告新闻批次和结构化诊断批次进度条。
