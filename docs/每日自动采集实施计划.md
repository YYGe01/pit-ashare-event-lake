## 1. 一句话结论

当前已经实现两条每日入口：

```text
qdc daily-pipeline   结构化日频采集入口
qdc crawl-daily      非结构化新闻公告爬虫入口
```

但它们现在仍是两个独立命令：

```text
已完成：daily-pipeline、crawl-daily、CNINFO 公告、Sina 新闻补位、因子和 Qlib 导出链路。
未完成：daily-pipeline 尚未自动调用 crawl-daily；全市场真实每日运行和连续调度尚未验收。
```

因此当前不要理解成“每日自动化已经全闭环”。更准确的状态是：

```text
代码能力基本接齐
小样本 smoke 已验证
一键联动、全市场真实运行、连续交易日稳定性和训练级覆盖报告还没完成
```

## 4. 当前命令怎么跑

初始化和环境验证：

```powershell
conda activate ai-trader
python -m pip install -e ".[market,dev]"
qdc validate-config
qdc init
qdc db-info
```

小范围结构化每日流水线 smoke：

```powershell
qdc daily-pipeline --date 2026-05-11 --symbols "SH600000,SZ000001" --batch-size 1 --control-only
qdc daily-pipeline --date 2026-05-11 --symbols "SH600000,SZ000001" --batch-size 1
```

小范围爬虫 smoke：

```powershell
qdc crawl-daily --date 2026-05-11 --control-only
qdc crawl-daily --date 2026-05-11 --source-id cninfo_announcement --page-size 2 --max-pages 1 --pdf-limit 1
qdc crawl-daily --date 2026-05-11 --source-id sina_finance_news --page-size 10 --max-pages 1
```

在一键联动完成前，建议按这个顺序手动跑每日完整链路：

```powershell
qdc crawl-daily --date 2026-05-11 --page-size 30 --max-pages 2 --pdf-limit 20
qdc daily-pipeline --date 2026-05-11 --batch-size 50 --export-start 2026-05-11 --market-name all_a
```

原因：`daily-pipeline` 会在采集后执行 `build-factors`、`sync-parquet`、`quality` 和 `export-qlib`。先跑 `crawl-daily`，同日新闻公告才会进入本次因子和 Qlib 导出。

## 6. 自动调度建议

在 `daily-pipeline --crawl-documents` 实现前，不建议只建一个计划任务。建议先用两个步骤或一个批处理脚本明确串行：

```powershell
qdc crawl-daily --page-size 30 --max-pages 2 --pdf-limit 20
qdc daily-pipeline --batch-size 50 --market-name all_a
```

如果使用 Windows 计划任务，建议先只做小范围或单日手动验证，再创建正式任务。DuckDB 当前按单写进程使用，运行写入命令前应关闭 `qdc console`。

恢复命令：

```powershell
qdc recover-running --older-than-minutes 60
qdc run-backfill --retry-failed --limit-tasks 20
qdc crawl-recover-running --older-than-minutes 60
qdc crawl-run --retry-failed --limit-tasks 20
```
