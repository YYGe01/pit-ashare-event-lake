## AkShare 数据源风险文档

- 目标：按用户要求不再把 AkShare 源码作为子仓库或本地 editable 包，而是先沉淀 AkShare 历史数据、PIT 和未来函数风险评估文档。
- 修改：新增 `docs/akshare_data_risk_assessment_zh.md`，梳理 AkShare 可下载历史数据的范围、bootstrap 适用性、严格 PIT 不足、各 logical_dataset 的未来数据风险和历史 backfill 规则。
- 决策：AkShare 定位为 bootstrap、低成本历史 backfill 和 shadow/fallback 来源；不能单独视为严格 PIT vendor。历史补采必须保留真实 `first_seen_at`，并显式区分 backfill 与每日 live observation。

## AkShare 风险治理方案

- 目标：按用户要求确认历史数据风险是否可通过处理解决，并补充已有行业实践依据，而不是只给抽象风险提示。
- 外部依据：参考 FRED/ALFRED vintage、LSEG/S&P PIT fundamentals、QuantConnect/LEAN corporate actions 和 security master、CRSP survivor-bias-free、Tushare 公告日期/上市退市字段、SEC EDGAR timestamp/API 等公开资料。
- 修改：扩展 `docs/akshare_data_risk_assessment_zh.md` 的第 11 节，新增可完全控制/可近似控制/不可从 AkShare 单源恢复三档判断、最小可实现字段方案、治理型 logical_dataset、各类风险对应解决方案、`market_available_at` 推导规则和最小实现顺序。
- 结论：AkShare 数据不是完全不能用；正确方式是区分 `pit_ready`、`approximate_pit`、`research_backfill`，并用 as-of 查询、生命周期、公司行为、披露时间和多源对账控制未来函数。
