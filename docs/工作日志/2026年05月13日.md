# 2026年05月13日

## P0 多源并行和超时容错落地

- 结构化 `daily-pipeline` 新增 `source_ids` 配置和 `--source-ids` 覆盖参数；默认配置为 `akshare`、`eastmoney`、`sina`，其中 Eastmoney 覆盖 `daily_bar` / `adj_factor` / `price_limit` / `trade_status`，Sina 覆盖 `trade_calendar`。
- 结构化任务新增 `daily_parallelism` / `--daily-parallelism`，支持多个 backfill task 并行执行，控制台 watch 会显示并行任务数。
- 新增 `EastmoneySilverCollector`，通过 AkShare 的 Eastmoney 历史行情接口写 raw、bronze 和 silver，并用前收盘价推导 `daily_bar.pre_close` 与涨跌停价。
- 文档爬虫 `_run_crawl_tasks` 改为源级并行，新增 `crawl_parallelism` / `--parallel-sources`、`crawl_request_timeout_seconds` / `--request-timeout-seconds` 和 `crawl_source_timeout_seconds` / `--source-timeout-seconds`。
- 新增 crawler runtime deadline helper；CNINFO、SSE、Sina、Eastmoney 和 NBD 文档源在请求、翻页、PDF 下载和源间等待时都会检查 deadline。单源超时写入 `crawl_task.last_error`，同 dataset 其他成功源继续保存 raw/silver。
- 新增 `nbd_company_news` metadata-only 新闻源，并纳入默认 `crawl-daily` 新闻源；文本因子和控制台文档口径同步识别 NBD。
- `daily-pipeline --crawl-documents` 的文档步骤改为 partial-success 口径：同一 dataset 只要至少一个源成功，就继续后续因子/同步/质量/导出；只有某 dataset 候选源全部失败或仍有未跑任务时才标记 partial。
