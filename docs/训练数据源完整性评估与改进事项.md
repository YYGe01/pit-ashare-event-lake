# 训练数据源完整性评估与改进事项

> 初始评估日期：2026-05-12
> 重写日期：2026-05-14
> 当前目标：明确 Qlib 基础行情底座和 QDC 非结构化外部因子的职责边界，避免继续用 QDC 全 A 爬虫补基础行情。

## 1. 总体结论

当前训练数据策略应调整为：

```text
基础行情、复权因子、交易日历、instruments
  -> 使用 Qlib cn_data 或 Qlib 仓库侧增量维护结果

公告、新闻、研报、舆情、监管处罚等事件数据
  -> 由 QDC 采集、清洗、归一化和构建 external factors
```

因此，后续不应把“补齐 QDC 自采 daily_bar / adj_factor / price_limit 长历史”作为训练前置主线。训练前置主线应改为：

```text
1. 确认 Qlib cn_data 更新到最近完整交易日。
2. 确认 Qlib provider 中 $open/$high/$low/$close/$volume/$factor 可读。
3. 用 QDC 生成外部文本和事件因子。
4. 在 Qlib 中做基础 Alpha158 与 Alpha158 + QDC external factors 对比。
```

## 3. QDC 当前数据资产判断

| 数据 | 当前定位 | 训练可用性 |
| --- | --- | --- |
| `daily_bar` | 历史能力 / smoke / 应急补数 | 不作为主训练底座 |
| `adj_factor` | 历史能力 / smoke / 应急补数 | 不作为主复权来源 |
| `price_limit` | 可选补充字段 | 后续按回测需要单独评估 |
| `trade_status` | 可选补充字段 | 后续按回测需要单独评估 |
| `announcement` | 当前主线 | 可先做事件 count、风险、融资、监管等因子 |
| `news` | 当前主线补位 | 免费源不支撑历史训练结论，需授权历史源 |
| `daily_announcement_factor` | 当前主线 | 可进入 Qlib 外部因子对比 |
| `daily_news_factor` | 当前主线 | 仅适合近实时和链路验证，正式训练需更稳新闻源 |

既有 AkShare 结构化采集能力不删除，但用途降级为：

```text
小样本 smoke
字段映射验证
临时缺口诊断
应急补一小段数据
```

不再用于默认全 A 每日采集。

## 4. 训练前最低要求

基础行情要求：

```text
Qlib cn_data 日历覆盖训练期
Qlib cn_data 中 $factor 存在且非全空
目标 universe 的 instruments 可读
抽样标的 D.features 可读
```

QDC 外部因子要求：

```text
publish_date 和 Qlib 交易日历可对齐
instrument 格式与 Qlib 一致
因子字段稳定、可重算
空值和无事件含义明确
source_object 可追溯
```

训练报告至少要记录：

```text
基础 provider_uri
基础 provider 最新交易日
QDC 因子日期范围
QDC 因子覆盖标的数
公告/新闻源级成功率和失败率
模型对照组和外部因子组配置
```

## 5. 公告完整性判断

公告是 QDC 当前最适合优先强化的事件源。

当前可用：

```text
cninfo_announcement
sse_announcement
公告标题、URL、发布时间、instrument 映射
PDF 下载和 hash 能力
规则事件分类
```

主要缺口：

```text
PDF 正文抽取
公告类型标准化
修订公告关系
SZSE / BSE 稳定补源
跨源去重和漏采校验
```

训练建议：

```text
先做公告 count、风险、融资、监管、诉讼、业绩、回购、担保、质押等规则因子。
先做 Alpha158 与 Alpha158 + announcement factors 的对比。
不要等待新闻历史源完善后才开始公告实验。
```

## 6. 新闻完整性判断

当前免费新闻源不适合作为训练级历史新闻库。

原因：

```text
Sina/Eastmoney 滚动页更偏当日或近实时。
NBD 稳定性一般，本地已有 SSL/502 失败记录。
厂商级 opt-in 快讯源覆盖和映射可观察，但不是完整历史源。
免费源无法证明长期历史覆盖率和一致口径。
```

短期用途：

```text
每日补位
控制台预览
事件映射 smoke
近实时外部因子实验
```

正式训练前应接入：

```text
授权历史新闻源
或可稳定按日期追溯、可审计、可长期维护的公开新闻源组合
```

## 8. 不再推荐的执行顺序

旧顺序：

```text
补齐 2015 至今 QDC 自采 daily_bar / adj_factor / price_limit
导出 QDC 基础 provider
再做公告和新闻
```

该顺序不再推荐。原因是 Qlib 社区 `cn_data` 已经提供更合适的基础行情底座，QDC 自采全 A 成本高、速度慢、复权口径也不如直接使用成熟 provider 稳定。

新顺序：

```text
1. 在 Qlib 侧更新 cn_data。
2. 在 QDC 侧校验 provider_uri。
3. QDC 采公告和新闻。
4. QDC 构建 external factors。
5. Qlib 侧跑 Alpha158 baseline 和 Alpha158 + external factors 对比。
```

## 9. 验收标准

训练前验收：

```text
Qlib cn_data 更新到最近完整交易日。
$factor 存在且抽样可读。
QDC announcement factor 日期和 instrument 与 Qlib 对齐。
QDC news factor 的覆盖和缺口有源级说明。
外部因子可被 Qlib handler 读取。
对照实验配置中清楚记录基础 provider 和 QDC 因子版本。
```

不再作为训练前验收：

```text
QDC 自己补齐 2015 至今基础行情。
QDC 自己维护完整复权因子。
QDC 跑完整 all_a 每日结构化采集。
```
