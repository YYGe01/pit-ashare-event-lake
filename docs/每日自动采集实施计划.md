## 4. 当前命令怎么跑

初始化和环境验证：

```powershell
conda activate ai-trader
python -m pip install -e ".[market,dev]"
qdc validate-config
qdc init
qdc db-info
```

小范围结构化每日流水线 smoke：

```powershell
qdc daily-pipeline --date 2026-05-11 --symbols "SH600000,SZ000001" --batch-size 1 --control-only
qdc daily-pipeline --date 2026-05-11 --symbols "SH600000,SZ000001" --batch-size 1
```

小范围一键联动 smoke，不访问真实爬虫和日线接口：

```powershell
qdc daily-pipeline --date 2026-05-11 --symbols "SH600000,SZ000001" --batch-size 1 --control-only --crawl-documents --crawl-page-size 5 --crawl-max-pages 1 --crawl-pdf-limit 1
```

小范围爬虫 smoke：

```powershell
qdc crawl-daily --date 2026-05-11 --control-only
qdc crawl-daily --date 2026-05-11 --source-id cninfo_announcement --page-size 2 --max-pages 1 --pdf-limit 1
qdc crawl-daily --date 2026-05-11 --source-id sina_finance_news --page-size 10 --max-pages 1
```

小范围真实联动 smoke：

```powershell
qdc daily-pipeline --date 2026-05-11 --symbols "SH600000,SZ000001" --batch-size 1 --crawl-documents --crawl-page-size 10 --crawl-max-pages 1 --crawl-pdf-limit 1 --export-start 2026-05-11 --market-name qdc_daily_smoke
```

`--crawl-documents` 会在结构化采集后、`build-factors` 前规划并运行默认爬虫源：`cninfo_announcement` 和 `sina_finance_news`。如果只想跑单个爬虫源，可加 `--crawl-source-id cninfo_announcement` 或 `--crawl-source-id sina_finance_news`。

## 6. 自动调度建议

正式调度前先完成小范围真实 smoke。通过后可把每日任务收敛成一个命令：

```powershell
qdc daily-pipeline --batch-size 50 --crawl-documents --crawl-page-size 30 --crawl-max-pages 2 --crawl-pdf-limit 20 --market-name all_a
```

如果使用 Windows 计划任务，建议先只做小范围或单日手动验证，再创建正式任务。DuckDB 当前按单写进程使用，运行写入命令前应关闭 `qdc console`。

恢复命令：

```powershell
qdc recover-running --older-than-minutes 60
qdc run-backfill --retry-failed --limit-tasks 20
qdc crawl-recover-running --older-than-minutes 60
qdc crawl-run --retry-failed --limit-tasks 20
```
