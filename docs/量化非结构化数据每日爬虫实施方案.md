## 已落地结论

```text
QDC 采用 crawler-lite，而不是单独引入完整 Scrapy 项目。
爬虫只服务每日新增积累，不承担多年历史新闻回补。
第一批 source 是 cninfo_announcement 和 sina_finance_news。
CNINFO 公告保留 raw JSON、bronze Parquet、silver announcement 和公开 PDF hash。
Sina 新闻只做 metadata-only 补位，不保存版权不明确的正文。
```

## 仍然有效的合规边界

```text
不绕过登录、验证码、付费墙。
不保存 cookie、token、账号密码。
不抓取需要授权才能访问的正文或付费数据。
对版权不明确的新闻正文默认 metadata_only。
raw/bronze 对象追加写入，不覆盖历史对象。
历史补采保留真实 collect_time，不伪装成当年可见数据。
```
